Drawn at 1:1. The busk view folds on the numbers the rest of the app already folds on — md 768 takes the rail and edit mode, the page body stacks its columns below 600px, and a viewport under 500px tall is short, which beats narrow. The app header stays on live views, so a landscape phone has 297px under the ShowBar and every default below is chosen for that.

9Short beats narrow. 852 is wider than md, so by width alone the rail would draw and the palette would be offered; by height there are 297px under the ShowBar. So the short fold wins: the rig strip and the page strip merge into one 32px row, Split shows one row of 48px tiles, and the defaults are Pads focus with the sheet folded. Edit mode is withheld here as it is below md: a palette drag needs both regions on screen and there is no room for both.

10The sheet opens as a right-hand overlay, 288 wide, the cell editor's own short-viewport form, with the Colour tab in its two-column compact layout (picker beside the fields). It overlays rather than docks because a docked 288px rail would leave 564px of body and a Colours bank four pads wide.

One rule under all of it: the fold decides the form, the window decides the choice. A phone never reads a rail and a desktop never reads a bottom sheet, but which tab is open, which focus is chosen and which page is showing are the same per-tab facts on every surface. Rotate a phone and the Colour tab it had open as a bottom sheet is the Colour tab open as a side sheet.

What is unchanged below md: no palette, no Edit layout, play mode only; Speed reached through the ShowBar's chip as today; the page's columns stack below 600px of body. The narrow-width target sheet is replaced by Rig focus, which is the same list with rows and cells.
