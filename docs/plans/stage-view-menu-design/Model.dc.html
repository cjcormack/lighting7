The starting proposal, tested

Held: split what you see from what it costs. Two tabs of one popover, so the header keeps one button and the rare settings stop pushing the frequent ones off screen.

Moved — the readout is per window, not per machine. Each window draws its own canvas at its own rate, and the two desk screens are two windows of one profile: a machine setting would put the counter on the hall screen as well. Its group on Performance is labelled this window; the three below it this machine.

Moved — the Show flags and Labels are per browser today, not per window: useStageView keeps them in localStorage. Hiding the rigging on the hall screen hides it on the desk too. They move to sessionStorage, a window with nothing stored reading the old key once, as the vis source did when it moved.

Found while drawing — Beam cones is the light switch. Off unmounts StageEmitters, which since light moved into the surface shader also packs the light table every surface reads: no beam, no pool, the rig dark (Balcony · desk with it off, left). Haze Off is what hides the cones alone. Renamed Light, hint Beams and every pool; the stored key stays beamCones.

Corrected: Venue · Set · Seating · Haze are per window but not announced — only the viewpoint and the source ride viewOptions. That stays; Work lights join the source, because it changes what the whole picture means and a plotting screen is a thing another window would set. The rest are this window's business.

Considered and declined

Keep the dropdown and add submenus (Haze ▸, Labels ▸, Light budget ▸). A submenu hides its current value until hovered, and every change is two hovers — a poor trade on the iPad.

Two header buttons, View and a gauge. The header already wraps at narrow widths (Edit drops to a second row at 800 px), and a control touched once per machine does not earn a permanent place.

One scroll with a Performance disclosure. Shorter than today, still taller than a 768 px screen once opened, and the readout's click has no clean place to land.

Work lights as a slider, or per machine. Off and on are enough to plot by, a level is one more number to argue with, and machine-wide work lights would light the hall screen's room too.
