Fixture and FX sheets · effects

The FX tray: pinned to the foot, started by a tap, edited live

An effect started on a sheet is a programmer effect — the same kind + Effect on the programmer and a busk pad make — so it plays over the programmer's values, Clear sweeps it and Record captures it. There is no Apply: picking one starts it and every change after that is on stage as it is made.

Absolute shows the centre the Around arm hides — the editor kit's 120px pad in degrees, made smaller — and the circle is drawn on it.

1
Live is the only mode.

Every control goes through useLivePush — a 50 ms floor, deduplicated, the release always lands — into a new socket frame, fx.update, which swaps the parameters and keeps the phase as PUT /fx/{id} does. Typed fields commit on Enter.

2
Revert, Done, ×.

Revert puts back the snapshot taken when the editor opened, in one write. Done goes back to the list and changes nothing. × stops the effect.

3
Sizes in degrees.

Where both axes carry a travel range, a radius is shown in degrees (60° = 28 of 255 on a 540° pan), with the byte as a read-out — the position cell's rule. Elsewhere, bytes.

4
One editor, three surfaces.

The tray's editor is the body of today's EffectParameterForm, rebuilt on the editor kit. The programmer rail's Edit… and FxSheet's chips open the same editor in EditorSurface, so ActiveEffectSheet and AddEditFxSheet's configure step go.

5
Groups and heads.

On a group, or a fixture with heads, the editor's Advanced gains Distribution and Element mode, as today.

6
Around current position is Additive with the centre pinned.

The desk's position blend adds effect − 128 to what the reset pass put underneath — the programmer's value, else the cue's, else the base. The arm hides the centre and sends 128; Absolute is Override with the centre shown. Movement effects start in Around (agreed); a stored effect with Additive and a centre of 128 reads back as Around.

7
Nothing held back without saying so.

A programmer effect is never held back by a programmer value. An effect that is — a cue's, a Look's, or an older manual one — is listed with an amber held back, and its row's chip carries the dot (Layers).

8
Where a started effect lives.

programmerOwned: true: Clear sweeps it, Blind stages it, Record and Record look capture it, ⌫ on its cell stops it. The sheet's Release stops it with the values. The ⌘K Apply FX sheet follows the same rule.

9
What does not change.

Effect templates, busk pads and cue effects are untouched; an effect a cue or a Look holds is still edited in its home. The FX Library is still where an effect type is defined.
