Docked editors only. They act on the marquee, so they list nothing. The tab claims its column's open gesture as it does today.

The tab segment opens row B. Values · Stack · FX · Scenery, each with a live count, which is all the collapsed rail's glyphs ever said. The scope picker (Output · Local · Layer) stays on row B for the Values tab only. A tab is a per-window view in ?table=, remembered like the Applied tables.

The FX lens. A cell an effect drives carries a violet chip with the division, read from one index built per fxChanged. When a value above beats the effect, the chip is struck through and its tooltip gives the reason (Programmer, Stomp, Blind), which is Per-fixture FX's one insight, now in the grid you are already looking at. Clicking the chip opens the live FX editor.

The right side is a dock, not a sheet. Colour and Spread only, collapsible to a 40px strip, with the same 260 floor and 300 default. It has nothing that lists, so nothing on it competes with the tables for a programmer event.

One stack, in its real order. The Applied tables split Looks from palettes, which hid the order that decides who wins. Here they are one table, top first, with Your values pinned above them as the row that beats every other. The kind chips give the split back as a filter.

Reorder by drag. SheetTable's rowDrag, positioned with top rather than translateY as the kit already requires. A drag is refused while a kind chip filters the list, because the gaps would make the drop ambiguous.

Focus moves here. A layer's ⏎, or Edit in grid, points the Values grid's scope at that layer and switches to Values. The rail's name badge used to do this. Your values' ⏎ points it at Local, and Make layer sits in its row as it does on the rail.

This is Applied FX, moved, not redrawn. Same columns, the same 1100 / 860 / 480 bands and the same verbs: Edit… (with the split edit), Pause, Save as palette…, Stop. + Effect is the bare effect press over the selection (POST /programmer/effects), so effects are created and listed in one place.

The rule rides with the rows. Values above beat effects below is the one thing the rail drew as a band. It sits under row B here and on the Stack tab, and links the two tabs.

Selecting an effect lights its cells. With an FX row selected, switching to Values rings the cells it drives. The index the lens builds answers this too, so the two tabs explain each other without a second grid.
