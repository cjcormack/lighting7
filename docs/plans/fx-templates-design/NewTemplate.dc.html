New template, holding an effect

The sheet is the one that ships today, in the same order. Two things change: a Holds choice appears under the family, and choosing Effect swaps the intent editor for the effect editor the desk already has.

1

Family first, still. The effect list is filtered by it — Colour offers the seven colour effects, nothing else — so there is no category step to repeat.

2

Beam cannot hold an effect. The library has no beam category (dimmer, colour, position only), so the Effect segment is disabled under Beam and says why.

3

Fade goes; Speed master takes its slot. An effect has no arrival to time. The default is By usage: the project master whose usage matches the family — the routing rule the busk plan left without a caller.

4

The configure step is reused, not redrawn. Speed, master, distribution, parameters and Advanced are EffectParameterForm as it stands, minus the target-specific rows (element mode, target setting) that need a fixture.

5

Runs on replaces Resolves to. A value resolves differently per head; an effect is one rule for all of them, with the distribution spreading its phase. So the panel counts the heads and previews one bar.

The other way in

A running effect in the programmer gets Save as template… — name it and it lands here with these fields filled. That is the effect twin of the strip’s New from selection, and it is how the library fills up without anyone visiting this sheet. See the Programmer artboard.
