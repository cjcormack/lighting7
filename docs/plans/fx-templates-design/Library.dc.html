The Templates view

One list, as today. Effect templates are rows in it, not a section or a second tab — the family bar is the only filter, and an effect belongs to a family exactly as a value does.

The tile is the tell

A value row keeps its swatch or its readout. An effect row shows the wave tile, tinted by family, in the same slot. The faint violet wash on the row is optional and probably unnecessary once the tile is there — drawn so it can be judged.

The subtitle says what it does

A value reads Generic · any fixture with colour. An effect reads Effect · Colour Pulse · ½ beat · M2 Chases: the effect, its speed, its master. Notes still win the line when set, as now.

Layer count means the same thing

Cue layers tracking the template. It gates delete the same way — and an effect template can also be running on the programmer, which the delete guard names (see Elsewhere).

Order is the operator’s

Sort order interleaves values and effects however they are arranged here. The busk pads split them at a hairline and keep this order within each half, so arranging the library arranges the pads.

Row menu

Edit · Delete, unchanged. Edit opens the same sheet with the Holds segment locked, the way the family is locked today. No Duplicate: a second effect is a second template, and the sheet is short.
