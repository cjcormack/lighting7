The vertical budget

One 1122×768 window (Chris's screenshot, 2026-09-21) in three states, drawn to scale. The number is chrome above the rig band; the band itself loses a further 32px to the merged row (Band.dc.html), drawn in the two right-hand columns. The rail's 64px come back sideways, which is one more pad per row on a 1122px screen.

Immersive is a fact of this window, beside the follow flag and full screen rather than beside focus: desk.immersive in sessionStorage, one value for all four live views, announced under whichever of them the window is on, set from the header glyph, ⌘K, the Screens sheet, or ?immersive=on at boot. It is not full screen and does not imply it — a windowed browser can be immersive and a full-screen one can show the app; the two compose, and the Screens sheet's Copy link carries it with the rest of the setup.

1One glyph, both ways. The expand glyph on the ShowHeader — a 40px chrome row now, on all four live views — is the control and the readout: outward arrows with the app drawn, inward arrows lit while immersive. It hides the sidebar (not collapses — hides) and the app header, and with them the four overview panels, whose toggles live on that header; their visibility is untouched, so they come back on exit. Nothing else moves: the ShowHeader keeps the switcher, Stop and the dot, so a window with no sidebar still has every way out.
2What the header took with it comes back where it is read. The blind report and the value count (ProgrammerIndicator) are on the Show tab's strip; the fold strip shows the live cue number under the Show glyph, green, so a folded sheet still says what is on stage. The connection pill is drawn on the ShowHeader only while the desk is offline — a chip that says Connected all night is the one thing immersive exists to remove. Theme, full screen and Screens… are ⌘K's.
3Immersive is per window, on all four live views, and is not full screen (Chris, 2026-09-21). A second desk screen launched from the Screens sheet arrives with it on (?window=Screen%202&immersive=on&page=…); the operator's main screen keeps the app. Layout reads the fact together with isLiveViewPath, so the Programmer, Show and the Prompt Book expand the same way from the same glyph on their shared header — and a window that leaves for the fixtures list gets the app back, since that list is navigated from the sidebar, and finds immersive waiting when it returns to any live view.
