The overlay sheet carries Colour · Spread · Show and still no Speed tab: the Show strip's tempo chip is the phone runner's own, so the reason Speed was withheld (the ShowBar had the chip) is met by the tab that replaces the bar. The bar is gone from every board of this view.

Six rules
1One component, not a copy. The tab mounts RunMobile — the phone runner Show swaps to below 600px — fed by the same useShowTransport instance routes/Busk.tsx already holds through useShowBarProps. The runner's display state (RunnerDisplayState) is built in ShowPage today; it lifts into a hook both pages call, so the tab and the phone cannot disagree about which cue is next.
2Collapsed by default here, Stage by default on the phone. The phone opens Current in Stage mode because there the card is the stage; on the busk view the rig band is, and two mini-stages a column apart would read as two answers. The toggle is still on the card; the sheet remembers the expansion per tab like any other per-tab fact, not persisted.
3Always locked. The phone runner is the always-locked layout, and that is what the busk view wants: no inline cue editing, click-to-arm on the list, nothing a stray press can change. The show-editing lock is not consulted, as it never was on this view; GO must work from here whatever Show's lock says.
4No transport keys. Space and ←/← stay unbound on the busk view: a pad is a button and Space activates the focused one, so a key that also fired GO would be two effects from one press. GO is the footer, a MIDI go binding, or the Show view one pill away.
5The strip carries what the bar carried and nothing more. Stack picker, cue list, the programmer chip (the view's blind report, now that the header's copy can be hidden), the tempo chip, DBO. DBO is still inert (FU-FE-DBO-INERT); moving it does not wire it up.
6Show is a live tab from the day it lands. It joins LIVE_SHEET_TABS, which lights it in the strip, the fold's glyph row, the Screens sheet's Sheet segment and the toggle's memory at once; ?sheet=show and a MIDI buskSheetToggle reach it by the same door. The desk's default sheet on a docked screen stays Speed; a window that wants Show open says so once and keeps it.
