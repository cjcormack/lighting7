In the window changed
busk.sheet 'none'|'speed'|'colour'|'spread'|'show' busk.lastSheet the tab the fold reopens onto — 'show' legal desk.immersive 'off'|'on' ← new, sessionStorage, default off one fact for all four live views, beside desk.follow and desk.fullscreen, not busk.* ?immersive=on consumed at boot like ?window=, stripped
Per tab, never the desk's. Same model as focus, rows and the sheet (lib/buskWindow.ts): createSyncStore over sessionStorage, null meaning not chosen, the reader resolving the default. Immersive's default is 'off' on every surface — nothing about a screen's size says the app should vanish.
Applies on all four live views (Chris, 2026-09-21). Layout reads useImmersive() together with isLiveViewPath (lib/liveViews.ts, the same predicate the sidebar's two-preference split uses), so a window on the fixtures list draws the app whatever the fact says — that list is navigated from the sidebar — and finds immersive waiting when it returns to any live view.
On the wire no new frame
windows.announce { …, viewOptions: { immersive: 'on'|'off', ← on every live view focus, rigRows, sheet, pageFollows, page? ← busk only } } windows.viewOptions { targetId, view: 'show', options: { immersive: 'on' } } ← same command ?window=Screen%202&page=3&focus=split &sheet=show&immersive=on ← Copy link
The registry never learns the word. viewOptions is a free string map (busk-further D13), so immersive rides it the way rigRows did — no lighting7 change for the Screens sheet, ⌘K or the setup link to set it. It cannot be a top-level announce key: the desk's Json is bare and one extra key drops the frame (windowsApi.test.ts pins the set). So the Programmer, Show and Prompt Book entries in WINDOW_VIEWS gain an options descriptor of one entry, and the Screens sheet draws a Chrome segment on every live-view row from it, generically. The Sheet segment gains Show from LIVE_SHEET_TABS.
MIDI, later if wanted. An ImmersiveSet(windowName, on) target would be BuskFocusSet's twin — addressed by registry name, judged by window health. Not proposed for this pass; buskSheetToggle already reaches the Show tab.

Other suggestions — three proposed with the two asked for, one decided by Chris, three considered and declined, one to decide
proposedThe live cue on the fold

With the bar gone, a folded sheet says nothing about the show. The fold strip gains the live cue number in green under the Show glyph, so Colour open or the sheet folded still answers "what is on stage" at a glance. Nothing is computed client-side: it is the server cursor the bar already read.

proposedOffline on the header, only when offline

The app header's Connected pill goes with the header. A red Offline chip on the ShowHeader, drawn only while the socket is down, keeps the one state that matters visible in immersive; a pill that reads Connected all night is exactly what immersive exists to remove.

proposedCopy link carries the shape

The Screens sheet's per-row Copy link already mints ?window=&page=&focus=&sheet=; immersive= joins it, so a second desk screen launched from the sheet arrives with no app around it. The row's Chrome segment (App · Immersive) sets it remotely like Focus does.

decidedThe header at 40

Chris, 2026-09-21: try it. The ShowHeader becomes a 40px chrome row with the same 32px controls on a 4px inset (px-3 py-1), on all four live views; the programmer chrome doc's "48 at every height" is revised by this. Immersive busk is then 40px of chrome above the band.

declinedFold the ShowHeader too

A "bare" rung with no header at all was considered. It takes the switcher, Stop, the live dot and the way back out with it; the way back would have to be a floating button over a live view, which the full-screen work already refused. 48px is the price of a window that can always leave.

declinedTransport keys while the Show tab is open

Space on a focused pad activates the pad; a key that also fired GO is two effects from one press on a live rig. Show binds them while locked because there nothing else takes Space. The footer, MIDI and the Show view are the routes.

decidedImmersive on all four live views

Drawn first as busk-only; Chris on 2026-09-21: build it for the Programmer, Show and the Prompt Book as well. So the fact is a window fact (desk.immersive), the glyph is the shared ShowHeader's, and Layout reads isLiveViewPath — the boards above are updated to say so.

decidedThe band's two rows become one

Chris, 2026-09-21: merge the label row into the controls row, dropping the summary where the tiles show it and keeping it in the gap in Pads. Band.dc.html draws the three shapes and the fold ladder; the family pill is kept beside the chip with its reason. Pad density stays FU-BUSK-PAD-SIZE.
