Where a value comes from A value is a literal or a reference to a palette. The blue ring says whose the value is; the teal edge and the pill say it is a reference, and to which palette. The same marks are used in Local, in Output, in a focused Look, in the cue editor and on the Look sheet.

The rules the boards assume
A palette press writes a reference into each selected head’s value, the palette’s own row for that head. A per-fixture palette’s rows for heads that are not selected are left out, and the press says so. ⌥click writes literals. A reference is a value like any other: a later value replaces it, Release takes it away, Undo brings it back. There is no layer. Creating a palette from the selection turns those heads’ values into references to it, on by default. Nothing moves on stage. Record, Include and Update copy values as they are, so a reference stays a reference in a cue or a Look. Copy the values makes it a literal. The pill always shows the palette’s name, never a short code.
