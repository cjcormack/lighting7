The busk pad face gains the word: ½ · M1 · around. Applies to the template sheet's Value cell editor too.

1
Instance edits stick until reset.

The desk keys a layer's running effect by its layer, effect and target, and leaves an existing instance alone on a re-cook, so a PUT /fx/{id} on a pad's effect survives every layer change until the pad goes off. edited is the client comparing the instance with its template's effect.

2
Reset to template needs one desk op — re-apply the template's effect to the instance in place, phase kept (W5). Update template is the template's existing PUT with these settings. Today a template's effect edit does not reach layers already applied (they keep their instance until re-pressed); session 1 checks that and, if so, Update also resets this instance's edited mark against the new template.

3
Release is W2 over a selection. The programmer's and the busk band's Release send one programmer.clearTarget per target in a single frame list; pad and Look layers are untouched, as Clear's narrowing would.

4
Existing templates. Nothing is migrated: a stored movement template keeps Override and reads as Absolute; the editor offers Around. Whether to flip the stock ones is an open call.
