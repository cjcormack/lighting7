It is a programmer surface, like a busk tab: every value lands in Local at the programmer fade, and every effect it starts is a programmer effect. 1
One header in every host.

Name and model, then a 40px chrome row: Values · Channels (and Focus in the Stage view), Locate, Park and Release n. No Edit / Done: the sheet is live whenever the desk is connected, and read-only only offline or on a parked property. The heads and mode badges move into the model line.

2
The scope line says where a write goes.

Local, at the programmer fade — the rail's picker, read and never set here. A blind programmer turns it amber: BLIND values staged, not on stage. On the right, what this fixture holds, which is what Release takes.

3
Families, in the desk's words.

Intensity · Colour · Position · Beam · Controls — the vocabulary of templates, the mask and Spread — replacing today's colour-first, settings-last order and the "Virtual" badges.

4
Every row says who is driving it.

A 3px edge and a chip in the programmer grid's colours: Programmer Effect Cue · Look Parked Base. A press on the chip opens the property's stack (Layers board). A slider takes the winner's colour, so a value an effect is moving reads violet.

5
A field on every row, in the row's unit.

The editor kit's EditorField: % for a level, degrees for an annotated pan or tilt, the step for a setting (a type-ahead list, as the grid's setting cell). Enter commits; the slider writes as it moves. The read-out line under a row is the kit's too (Focus: sharp at 9.4 m).

×
× clears one value.

Drawn on a row only while the programmer holds that property; it is programmer.clearEntry at the programmer fade, so the row falls to what is underneath and its chip says what that is. Release n clears all of them and every local effect on the fixture.

6
The effects are pinned to the foot.

A 40px tray that never scrolls away: its count, a chip per running effect (dimmed while paused) and + Effect. A chip opens the tray on that effect. Effects that reach this fixture through a group are listed with via Front wash.

7
Open, the tray takes the height it needs.

Up to half the sheet; the properties keep the rest and scroll. Its rows are the programmer rail's two-line rows (name, division, target, home), with pause and stop.

8
An effect is edited live.

No Apply or Update: each change is sent as it is made (a 50 ms floor, the release always lands) and the effect keeps its phase. Revert puts back the settings it had when the editor opened; × stops it. A movement effect asks only one question first — Centre: Around current position | Absolute — and in Around it hides the centre and offers sizes in degrees.
