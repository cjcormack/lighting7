Only the normalised half
Continuous roles are cross-type as a 0–100% of each head’s own range — and strobe as Hz, which is the only unit two fixtures agree on. Slotted properties are not: “gobo 3” is a different pattern on every model, so a template cannot carry it without lying.
So where do slotted properties live?

In a recorded look — which names its own fixtures and can therefore hold anything those fixtures have, gobo slots included. Nothing is lost by dropping the type from templates; the type-specific case moves to the entity that already carries a type by naming a head.

That also makes the two kinds mean something distinct at last: a template is a rule (“be amber”), a recorded look is a fact (“these heads were like this”).
