The two property visualisers keep the picker-only form they have.

Save as template…PickSpread…

The popover is 352 wide and the picker is fluid: the square takes what the R/G/B column leaves, as it does in the busk sheet at 320–480. Today it is a fixed 200px square (index.css, !important) in a w-auto popover; the six mount sites that rule names become one.

The read-out replaces the count line. Emitters on 6 of 14 heads · the rest take RGB only is the selection's union read off the colour descriptors, per head, with the count beside each emitter row — the same probe the busk tab runs (emitterHeadCounts). The swatch, the hex and mixed sit at its right. 4 heads · Local moves to the label line above the picker, where the Spread panel puts it.

Pick reads the selection's live colour off lib/liveAppearance.ts into the picker without writing — the first head in rig order, mixed where they disagree — exactly as the busk tab does. In the programmer the editor already opens at the first cell's value (the placeholder rule); Pick is how a batch is re-read after a drag moved only some of it. The grid's rows report into the store as the rig tiles do, so no hidden leaves are needed here.

Save as template… opens NewTemplateFromSelectionSheet over the marquee's heads, family Colour — the strip's New with the family answered. Spread… opens the Spread panel with From set to this colour's RGB, the busk hand-over (SpreadSeed): on the programmer it opens at the Spread button, since that is where the panel lives. Both are the footer the busk tab has; neither is new.

Recent is not drawn in the desk popover (open call 2): row C's strip is on screen one row up, and a chip set drawn twice is the double the rule refuses. It is drawn in the bottom sheet, where the strip is folded away below 600px — so the phone gets Recent in the editor, as the busk phone does.

The white-LED guidance is the picker's title everywhere, as the compact layout already made it; the paragraph is gone. The keyboard is unchanged: R focused on open in the popover, comma R → G → B → W → A → UV, Enter closes, a typed character seeds R.
