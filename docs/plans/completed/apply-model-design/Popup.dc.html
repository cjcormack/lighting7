The palette popup: the cell editor every family already has, with that family's palettes above it and its effects below (D4). Sleeping Beauty's fixtures; palette names illustrative.
1The header names the heads the press lands on (the cell batch) and the mask, which is the cell's own family, as a Sel · property fader names its own attribute.
2Palettes that fit these heads, recently pressed first, then by name; All … opens the picker on this family. A ring is the pad's: solid when every head has it, dashed when some do. A tap is the press: a layer that tracks (D1), replacing the family's other value palette on these heads (D2, D6).
3The editor is unchanged. A drag or a typed value is a Local value, above every layer, as today.
4Effects: what runs on these heads first (lit), then the family's effect palettes, then + Effect … for the library. An effect palette is a layer; a library effect is Local (D5).
5With a Look layer focused the press goes into the Look (D7): a palette's values written per head into its rows, an effect into its effects. No rings, since a Look holds values, not palettes.
6Save as palette… from every family, from the cell's current values (Colour had it alone).
7A setting cell keeps its type-ahead and has no palette band; Beam cells offer the Beam palettes that set their property.
