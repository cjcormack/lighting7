2Chips are the same selection as everywhere. Tap one to set the desk selection (selection.set), so the programmer, the busk band and the Stage view all follow. The swatch is live colour at level; a batten's swatch is split per cell; the Twin Shot shows a flame and its loaded tubes, never a level.
3Replaces StageOverviewPanel behind the same header toggle, on every route. Today's panel places 45 names by percentage in a 420 px box with no decluttering; this one cannot collide, and reads on a phone as the same rows stacked.
4Plan survives as a camera. The panel's second tab is the Stage view's orthographic plan, rendered by the one renderer. Open in Stage jumps to the full view with the same camera.
5Group chips are kept and now filter by dimming: chips outside the group fade, rows keep their place, so the geometry never jumps.
