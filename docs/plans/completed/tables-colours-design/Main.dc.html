The programmer is the table, and fixtures carry a colour

Two asks. First, retire the separate Applied FX / Looks / Palettes view, and fold the rail's stacked lists (the layer stack, the effects list and the Per-fixture FX sheet) into the programmer's own tables. Second, give fixtures and groups a user-set colour that every view can show, as ChamSys does. Both must keep today's responsiveness. Dark-only and drawn 1440 wide, like the earlier records. Phone and tablet layouts are a second pass, except where a fold changes the shape.

An effect's row appears in the rail's Effects list, in Applied FX, and as a chip in Per-fixture FX, which builds its own copy of the grid's row model. Layers appear twice too. Each copy has its own width, its own folds and its own verbs, and the rail is the only place where a layer can be reordered.

Each fact appears once, at full width, in the sheet kit's virtualised table. The tabs carry counts, which also replace the collapsed rail's glyph counts. The right side keeps only the docked editors, which act on the marquee and list nothing.

1 · The programmer is the table. Row B starts with a tab segment: Values · Stack · FX · Scenery, each with a count. Values is today's grid. Effects are drawn in its cells as a wave chip with the division, struck through when held back, so Per-fixture FX is retired along with its second row model. Stack is the Applied Looks and Applied Palettes tables merged back into one table in stack order. It has a pinned Your values row, the layer rows, drag to reorder and chips to filter by kind. FX is Applied FX. Scenery is the rail's band as rows.

The rail becomes a dock with only Colour and Spread. /programmer/applied redirects to /programmer?table=. The per-window table fact moves with it, so the Screens sheet's Table segment still points a second screen at FX.

2 · Fixtures carry a colour. A fixture and a group can each hold one colour from a fixed named set of ten, chosen to avoid the hues the desk already uses for meaning (blue for yours, amber for parked, violet for effects, sky for cues, teal for Looks). The colour marks identity only: the name cell, a busk tile's top band, a stage label, a DMX footprint, a surface's target label. It never fills a value cell or draws a ring, because those already say who owns a value.

You set it in the patch list's new Colour column, in bulk with the marquee, or with Colour from group. colour:red filters any list, and Select colour… selects by colour. It is portable show data (sync v36), and on a venue it is the venue's, which a show can recolour.

Responsiveness: the rules both proposals keep
RuleWhy, and what it costs
The Values grid never unmounts on a tab switchUnmounting clears the scoped selection (useListSelection), which is the rule the grid must never remount on a scope change already guards. The other tabs mount on demand over it, and the grid stays mounted but hidden. Hidden, the virtualiser measures nothing and draws no rows, and the programmer event that re-renders it today keeps doing so. There is no new cost.
The FX lens reads one indexEffects are indexed once per fxChanged, keyed by head and property, using the rows the grid has already built. A cell reads its key through the selector store usePropertyValues already uses, with no subscription per row. Per-fixture FX built a second full row model and re-rendered on every programmer event. Removing it is a saving, not a cost.
Stack and FX are the shipped tablesAppliedTableShell, SheetTable, memo rows, overscan 8 and the 1100 / 860 / 480 width bands, all unchanged. Only the frame around them moves. The rail's two hand-built lists stop rendering, so a programmer event has fewer subscribers.
A colour is static data, resolved onceResolved when the row model is built, from the patch and group lists RTK Query already caches, and drawn as a CSS variable --tag on the row. A tag edit re-renders only the rows whose tag changed, and nothing reads it at frame rate. There is no new WebSocket frame: tags ride patchListChanged / groupsState.
3D colours are written on change, never per frameOne colour per body instance, written through the same setColorAt path selection uses and only when a tag changes. The billboard glyphs gain one per-instance attribute alongside aActive. Housings are tinted only when the view option is on.
Measured before it shipsThere is no table performance test today. Each plan session records React Profiler commit times on the 1180×820 iPad frame and on the desk for a programmer event on a 120-fixture rig, a fader drag and a tab switch. A session that regresses any of them does not merge.
Calls · decided with Chris, 18 Oct 2026
#CallDecision
1Tabs only, or tabs plus a split? You sometimes want Values and FX on screen together.Tabs, with the in-cell FX lens covering the side-by-side case. A second screen covers the rest, since the Screens sheet already sets a window's table. A Values-over-FX bottom split, like the cue editor pane, is the fallback if the lens is not enough.Decided
2Does the rail keep the Stack?No. The dock is Colour · Spread. Reordering moves to the Stack table's drag handle (rowDrag), and the collapsed strip's counts move to the tab counts. On the phone, the bottom sheet hosts the dock and the tabs fold to glyph and count.Decided
3Scenery: a tab or the Stack's top band?A tab. It is addressed by element and never by the selection (D3), so it has nothing to share with a layer row's columns. All scenery… becomes the tab's filter chips (Set, Venue, Moving only).Decided
4Looks and Palettes: one Stack table or two?One. A programmer's layers are one ordered stack where top wins, and the Applied split by kind hid that order. A kind chip (All · Looks · Palettes) gives the split back as a filter.Decided
5A fixed named set, or any hex?A fixed set of ten. Names (red, lime, …) are what colour: filters and MCP read, each has a light and a dark value, and the set leaves out the reserved hues. Any hex would let someone tag a fixture Look-teal.Decided
6Does a group's colour reach its members?No inheritance. A head in three groups has no single answer. A group's colour marks the group's row and tile, and Colour from group copies it onto members explicitly.Decided
7A colour on a venue's fixtureThe venue owns it, versioned and classed as drawing-only, so it never puts a show behind on output. A show recolours through a small show-owned table keyed by record uuid. That covers venue groups too, which a facet could not, and needs no base and no drift.Decided
8Its name"Colour", with the verb Set colour. Highlight is already the momentary dimmer-to-full verb on the selection bar, so it cannot also mean a tag.Decided
9Stage view: tint the housings?As a view option (Bodies: Plain · By colour), off by default. The label chip carries the colour either way, and a selected housing still turns primary blue.Decided
