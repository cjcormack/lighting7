A template can hold an effect

It stays what it is — one attribute family, no targets of its own, applied to a selection — and the named thing it holds can now be a value or an effect. Same library, same pad, same chip, same two gestures. Nothing on the busk view mints an anonymous effect; it presses a named one.

What stays the same
1

The family is chosen first and is the template’s identity. An effect template’s family is the effect library’s category — dimmer is Intensity, colour is Colour, position is Position.

2

No targets. A layer supplies them, so the same template sits on two selections as two independently-toggleable pads.

3

The layer is the dependency: retune the template and every layer tracking it moves — for an effect, every running instance retimes.

4

The per-use overrides a layer already has — tempo master, amount, mask, stomp, enabled — are the whole per-use story. Nothing new on the layer.

What is new
1

Holds — a second identity choice under the family: Value or Effect. Fixed after creation, like the family.

2

The effect editor is the existing configure step of Add Effect — speed, master, distribution, parameters, advanced — with the effect list filtered to the family. No fade: an effect has no arrival.

3

Runs on replaces Resolves to: an effect is one rule for every head rather than a per-head resolution, so the panel counts heads and previews one bar rather than listing channels.

4

A running effect can be saved as a template from the programmer — the effect-side twin of New from selection.
