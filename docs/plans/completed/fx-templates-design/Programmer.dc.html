Save as template… on a programmer-band effect is the effect twin of the strip’s New from selection: it asks for a name and creates a template in the effect’s family with these settings, leaving the running copy where it is. It is offered on an effect the programmer owns, not on one a Look or a template already owns.

+ Effect stays disabled while an effect-template layer is focused, for the value template’s reason reworded: A template holds one effect. Switch to Local for an effect on this cue, or focus a look layer to put one in its look.
