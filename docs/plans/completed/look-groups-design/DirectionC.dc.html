One pad, two meanings. Amber Key sits in a solo bank and a stacking bank. Its ring is per record, so it lights in both; but a press in Key colours releases Steel Blue and a press in Extras does not. The toggle route would need to know which pad was pressed, and the ring could no longer promise "press me and I invert".

Library pages keep a flat, separate order. Template groups either vanish from /templates or become a second grouping with a different meaning.

Migration. Every existing template group becomes a solo bank on page 1; the family columns become a default page layout the operator can break.

For. It is what the busking desks do, and it buys three things the recommendation does not: pages, the same pad in two places, and a layout per show that is not the library's order.

Against. Two orderings to keep straight. A new table with its own sync story. A pad identity in the toggle API. And it undoes the busking-view decision that a busk pad is a library record rendered as a pad — the reason the effect-pad grid was cut in §4a.

The tell. None of its three gains is in the brief. The brief asks for exclusivity across kinds, which the recommendation gives with one column and one rule reversal.

Where it fits. Later, if pages are ever wanted. A bank would then reference library groups the way a cue layer references a Look, so nothing done now is thrown away.
