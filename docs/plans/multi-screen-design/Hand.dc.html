The hand: moving a thing between windows

No browser can drag a dnd-kit element out of one window and into another, and no browser at all can drag from a desk screen to an iPad. So the move is a desk fact rather than a pointer gesture: a record is picked up into the hand, the desk broadcasts it, every window draws it and lights its drop targets, and a tap in any window places it. The same mechanism serves touch on one window — it is a cut-and-paste with a visible clipboard, which is what a desk's Move key is.

Chrome's Window Management API says where each window sits on which display, so a drag that crosses the boundary can be handed over as a pointer position on the other screen rather than as a dropped chip. The hand is what makes it safe: if the other window is not there, or is an iPad, the drag ends as a pick-up and nothing is lost. Same-origin windows in one browser can carry the ghost over BroadcastChannel without a round trip to the desk; the desk frame is the source of truth either way.
