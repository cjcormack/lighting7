Rows, columns, banks

Solo never decides a bank's shape. A page is rows; a row is columns with a width share; a column stacks banks; a bank's pads wrap or run as one column. Two horizontal banks stacked beside a vertical one is a row with two columns, and any number of rows follow.

Three zones light up under a lifted bank: beside a column, which opens a new column; under a bank, which stacks it in that column; below the page, which starts a row. A column left empty is removed, and a row left empty with it.

Widths are shares, not pixels, so a page drawn at desk width keeps its proportions on a smaller screen until the columns stack. Nothing is positioned by hand and nothing can overlap.
